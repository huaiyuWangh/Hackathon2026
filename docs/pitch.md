# VoiceCopilot 路演材料

> 一句话：对设备说句话，你的 Mac 就开始写代码，结果读给你听。
> 配套：[README 产品页](../README.md) · [演示剧本](demo-script.md) · [品牌资产](brand/)

## 第一页：三层故事

### 生态层（主叙事，讲给评委/灵矓方）

> **端侧 MCP 让任何灵矓设备获得"无限技能"。VoiceCopilot（bridge）是第一个技能——编程副驾驶。**

- 硬件从"陪伴型设备"升级为**生产力入口**，每多一类技能就多一个买硬件的理由；
- 分钟级任务的语音交互密度远高于闲聊陪伴，天然拉动 ASR / LLM / TTS 用量；
- 技能可由开发者社区供给（技能市场），生态飞轮。

### 用户层（讲给用户）

> 把 AI 编程从键盘前解放。

- 通勤路上收到 CI 告警 → 说句话 → 到家前测试绿了；
- 长任务托管，结果读给你听，不盯屏幕；
- 躺在沙发上语音 review："这周谁动了支付模块？"

### 情感层（一页带过）

视障开发者的第一条"用嘴写代码"的通路：下发、追问、播报整个闭环不依赖任何屏幕。

## 第四页：AI 元素盘点（产品里有 5 个 AI 在工作）

1. 灵矓 realtime ASR（服务端 VAD，无唤醒词）
2. 意图模型 `Intent_function_call`
3. 平台 LLM：意图理解 + 调度 + 摘要
4. Claude Code：代码理解与执行的 LLM 智能体
5. TTS 播报

**双 Agent 分层协作**：平台智能体是"耳朵、嘴和调度员"，Claude Code 是"手"。

### AI 自主性清单（答辩举证用）

| 自主行为 | 证据 |
|----------|------|
| 自主选择工具与时机 | 聊天记录：收到意图即调 `dev.claude.send` |
| 自主轮询节奏 | status 间隔由智能体决定，非固定定时器 |
| 摘要化播报 | diff/日志压成两三句人话（M5 实测） |
| 多轮上下文 | 追问"动了哪个文件"直接命中（2026-10-23 验证） |
| 危险操作先确认 | 系统提示词：rm/git push/部署先语音确认 |
| 可被打断 | 人声打断 TTS；`interrupt` 打断任务 |

## 第五页：答辩话术

- 开场："这是一个 Agent 指挥 Agent 的产品——人只负责说和听。"
- 被问"和手机 App 操控有什么区别"：零注意力 + 打断自然 + 全入口复用（见画布差异化）。
- 被问"语音通道能执行任意 shell，安全吗"：interrupt 兜底 + 危险操作语音确认 +
  控制面只绑本机（观看不等于控制）；工程深挖见 issue #7。
- 被问"凭什么两天做完"：AI 工程效率方法论——方案先行/验收前置/分层解耦让 AI 可自测/
  排障探针产品化（issue #9 有完整时间线与 commit 证据）。
- 收尾："bridge 只是第一个技能——你的 Mac 上还有多少工具值得被听见？"
